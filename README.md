
# 터치 연습 · Touch Practice (웹 체험 버전)

터치, 길게 누르기, 드래그를 숫자 짝 맞추기로 연습하는 게임 "터치 연습"의 **브라우저 체험용 웹 빌드**입니다.
A browser trial build of "Touch Practice", a number-matching game for practicing tap, long press and drag.

## 이 저장소는
- 안드로이드 앱 "터치 연습"과 같은 게임을 설치 없이 브라우저에서 체험하기 위한 **빌드 결과물**(HTML/JS/WASM)입니다.
- 앱의 **소스 코드 저장소가 아닙니다.**
- 개발 블로그에서 안내하는 용도로 올려 두었고, 검색 엔진에는 노출되지 않도록 설정했습니다.

## 웹 버전의 특징과 제한
- 인터넷 연결이 필요합니다. (안드로이드 앱은 오프라인으로 동작합니다.)
- 진동이 없고, 효과음은 처음 터치한 뒤부터 납니다.
- 기록과 설정은 **사용 중인 브라우저에만** 저장되며, 앱의 기록과는 별개입니다. 브라우저의 사이트 데이터를 지우면 함께 삭제됩니다.
- 광고, 분석 도구, 개인정보 수집이 없습니다.
- 실행에 필요한 파일과 글꼴은 모두 이 사이트에서 제공하며, 외부 서버에서 받아오지 않습니다.

## English
This repository contains the **build output** (HTML/JS/WASM) of the web trial version of "Touch Practice". It is **not** the source code repository.

- Needs an internet connection. The Android app works offline.
- No vibration; sound starts after your first tap.
- Records and settings are stored only in your browser and are separate from the app.
- No ads, no analytics, no personal data collected.
- All files and fonts are served from this site; nothing is loaded from external servers.
- Open-source: Flutter (BSD-3-Clause); a subset of Noto Sans KR (SIL OFL 1.1, see `assets/assets/web/OFL.txt`).
